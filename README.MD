# Personal Task Timer

A simple personal productivity app for tracking the time spent on long-term goals and tasks.

## Features

- Create tasks with custom time goals
- Start and pause task timers
- Track completed and remaining time
- Live session timer
- Persistent progress stored in PostgreSQL
- Clean, responsive interface

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Backend:** FastAPI, SQLAlchemy
- **Database:** PostgreSQL

Built as a personal tool for tracking focused time across different goals while practicing full-stack development with React, FastAPI, and PostgreSQL.
